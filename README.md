# Baller: Basketball Statistics Tracker

## Overview
Baller is a basketball statistics management program built in Java, designed to help teams and enthusiasts track player and game performance. The application features a user-friendly interface to add teams, manage player stats, and view detailed performance metrics. Users can save and load data for long-term tracking.

## Features
- **Add Players:** Create new players with attributes such as:
  - Name
  - Jersey number
  - Position
- **Record Game Stats:** Log detailed statistics for each game.
- **Statistics Dashboard:**
  - Identify the best player in specific stat categories.
  - Generate an all-star roster based on player performance.
- **File Management:** Save and load player and game data using the menu options.

## How to Run
### Prerequisites
- Java Development Kit (JDK) installed on your system.

### Steps
1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Navigate to the project directory in your terminal.
3. Compile the source code:
   ```bash
   javac Main.java
   ```
4. Run the program:
   ```bash
   java Main
   ```

## Usage
1. **Main Menu:** Use the main interface to add teams and view statistics.
2. **Add Players:** Enter player details, including name, jersey number, and position.
3. **Record Game Stats:** Log game-specific statistics for detailed tracking.
4. **View Stats:** Use the dashboard to identify standout players and create all-star rosters.
5. **File Options:** Save your progress or load previously saved data using the "File" menu.
