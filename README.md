# CPSC 233 FINAL PROJECT
## Baller: The Basketball Statistics Tracker Program

Baller is a program created to add and view stats for Basketball teams. On the main menu you can add a team and view 
various statistics, such as a players last name, the best player in a specified stat, and a roster created from all-star 
players. 

Both the Add Player and Add Game buttons will take you to a sub menu. Adding players requires a players name, jersey number, 
and position. Adding a game requires each stat from the game you are adding. 

You can save and load files from the "file" button on the menu bar in the top left from the main menu.
